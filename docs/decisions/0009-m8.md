# 0009 — M8（发布 v0.1）细节决策（2026-10-20）

| # | 事项 | 决定 | 理由 |
|---|---|---|---|
| 1 | 备份 | `wingmanager backup --data-dir <dir> <dest>`：在新目录 `<dest>` 里生成 `wingmanager.db`（用 `VACUUM INTO`，服务运行中也安全）和 `files/` 的副本；`<dest>` 已存在就报错，不覆盖 | 备份 = 一个目录，拷走就行 |
| 2 | 恢复 | 不做命令：README 写明"停服务 → 用备份目录替换数据目录 → 启动" | 少一个会出错的命令 |
| 3 | 重置密码 | `wingmanager reset-password --data-dir <dir> --password-stdin`：从标准输入读新密码（同样的长度规则），并删除所有会话 | 不引入读密码的终端依赖；忘记密码时唯一的出路 |
| 4 | 演示数据 | `wingmanager seed-demo --data-dir <dir>`：只在没有任何账号的实例上运行，否则报错。生成演示账号（打印邮箱和随机密码）、两个房产、相对今天的短租订单和导入样式订单、一份进行中的租约（含收款和逾期）、当年支出 | 截图、试用、验收都靠它 |
| 5 | HTTPS 反向代理 | 新增 `--behind-https-proxy` 参数：开启后会话 cookie 一律带 `Secure`。不读 `X-Forwarded-*` 头 | 部署在 Caddy 等代理后面时 cookie 仍安全，又不用信任可伪造的请求头 |
| 6 | Docker | 多阶段构建，`CGO_ENABLED=0`，运行镜像用 distroless static、非 root 用户，数据卷 `/data`，默认命令 `serve --addr 0.0.0.0:8080 --data-dir /data` | 和单文件二进制同一份产物 |
| 7 | 二进制发布 | GitHub Actions：推 `v*` 标签时为 linux/amd64、linux/arm64、darwin/amd64、darwin/arm64、windows/amd64 构建，附到 Release；同时构建并推送 GHCR 镜像。版本号通过 `-ldflags` 注入，`wingmanager version` 打印，本地构建显示 `dev` | 不引入 goreleaser |
| 8 | README | `README.md`（英文）+ `README.zh-CN.md`（中文），内容一致：是什么、下载运行、Docker、HTTPS 部署示例（Caddy）、备份恢复、重置密码、演示数据、开发命令 | 开源项目 + 中文房东 |
