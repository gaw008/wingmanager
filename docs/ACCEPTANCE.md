# 发版验收清单

每次发版前，从**空实例**开始照这份清单走一遍：中文、英文各一遍，桌面 1280px 和手机 375px 都要看。
每一项写明"做什么"和"应该看到什么"。任何一项不符合都算未通过，修好后从受影响的部分重走。

准备：`go build -o wingmanager ./cmd/wingmanager`，用一个新的 `--data-dir`；另开一个本地静态服务器提供 iCal 样例（`internal/ical/testdata/`）。

## 0. 自动化检查

- [ ] `AGENTS.md` 里的全部命令通过（gofmt、vet、staticcheck、sqlc diff、`go test -race ./...`）

## 1. 首次使用

- [ ] 打开任意页面 → 跳到首次设置页
- [ ] 7 位密码被拒；8 位以上成功创建房东账号 → 跳到登录页
- [ ] 错误密码 → 提示错误；正确密码 → 进入"今天"
- [ ] 再访问首次设置页 → 不能再创建第二个账号
- [ ] 设置：改时区、币种、语言为英文 → 全站变英文；非法时区被拒

## 2. 房产、单元、联系人

- [ ] 新建房产 → 自动带第一个单元和日历导出链接
- [ ] 加第二个单元成功；同一房产里重名被拒
- [ ] 归档单元成功；归档最后一个活跃单元被拒；恢复成功
- [ ] 重新生成导出链接 → 旧链接 404
- [ ] 新建、编辑联系人；按名字搜索（中文、英文大小写）

## 3. 短租订单与日历

- [ ] 在日历点空白格 → 新建订单表单带好单元和日期；保存后色条出现在正确位置
- [ ] 同日交接（A 退房日 = B 入住日）→ 允许，两条色条首尾相接
- [ ] 重叠订单 → 被拒，并列出冲突的订单
- [ ] 不存在的日期（2 月 30 日）→ 被拒
- [ ] 取消订单 → 日期释放、保洁任务取消；恢复时若日期已被占 → 被拒
- [ ] 每个确认的入住在退房日有保洁任务；改日期后任务日期跟着变；屏蔽没有保洁任务
- [ ] 已归档单元上不能建订单
- [ ] 日历：月份切换、"今天"按钮、房产筛选、点色条打开详情抽屉、Esc 关闭；手机上日历在自己的容器里横向滚动并定位到今天

## 4. iCal 同步（PLAN §9 场景 1）

- [ ] 添加日历源指向本地 Airbnb 样例 → 同步后出现入住和屏蔽，入住带保洁任务
- [ ] 再同步一次 → 没有重复订单、没有重复任务
- [ ] 日历源换成**空日历** → 一个订单都不取消，显示警告
- [ ] 换成 **HTML 错误页** / **404** → 订单不变，显示"同步失败"，技术详情可展开
- [ ] 去掉一个未来订单 → 该订单取消、保洁任务取消；过去的订单不动
- [ ] 导入订单的日期不能改，客人和备注可以改
- [ ] 手动订单和导入订单重叠 → 手动订单被拒；两个导入订单重叠 → 日历和首页显示冲突
- [ ] 删除日历源 → 它导入的订单变成手动订单，不被取消
- [ ] 导出链接：只含已确认订单和生效租约，内容是 "Not available"，没有客人姓名
- [ ] **真实 Airbnb 链接**同步一次（需要房东提供链接；没有就在报告里写"未验证"）

## 5. 长租（PLAN §9 场景 2）

- [ ] 新建草稿租约；没有租客时激活被拒；加租客后激活
- [ ] 和已确认的短租重叠时激活被拒
- [ ] 月中开始的租约：首月按天折算，金额正确；之后每月 1 次整月应收
- [ ] 刷新页面、重启程序 → 应收不重复
- [ ] 收款弹窗：输入金额时实时显示冲抵哪几个月、保存后余额；部分付款后逾期天数按先进先出正确
- [ ] 自动房租应收不能作废；其他账目作废要填原因，作废后不计入余额
- [ ] 收押金、用押金抵扣 → 押金持有和欠款同时变化
- [ ] 修改月租 → 只影响以后的月份
- [ ] 结束租约 → 之后不再生成应收；生效租约期间不能订短租
- [ ] 长租列表的"逾期"标签只列逾期租约；旧的 `/overdue` 地址跳转过去

## 6. 账本与报表

- [ ] 记支出（各类别）、记收入（短租打款可关联本房产订单，关联别的房产订单被拒）
- [ ] 年度报表：收入 = 收款 + 其他收入，支出 = 支出，押金和作废不计入，跨年日期归入正确年份
- [ ] Schedule E CSV、明细 CSV 能下载并能用表格软件打开，数字和页面一致，带免责说明
- [ ] 未登录访问 CSV → 跳到登录页

## 7. 任务与文件

- [ ] 新建维修任务、完成、重新打开、取消；保洁任务不能手动取消或新建
- [ ] 在房产、单元、租约、联系人、账目上各传一个文件；下载内容一致
- [ ] 上传 HTML 文件 → 下载时作为附件，不在浏览器里执行
- [ ] 超过 20 MB 被拒；删除文件后记录和磁盘文件都消失

## 8. 首页"今天"

- [ ] 今天入住、今天退房、逾期租金、今年净收入四个数字和各页面一致
- [ ] 预订标签（今天退房 / 今天入住 / 入住中 / 即将到来）内容正确，空状态有提示
- [ ] "需要处理"列出逾期租客、到期任务、同步失败的日历源，按钮可直接操作

## 9. 运维命令

- [ ] `seed-demo` 在空实例上成功，有账号时拒绝
- [ ] `backup` 生成数据库和文件副本；目标已存在时拒绝；用备份目录替换数据目录后能正常启动
- [ ] `reset-password --password-stdin` 改密码并让所有会话失效
- [ ] `--behind-https-proxy` 时登录 cookie 带 Secure
- [ ] `version` 打印版本号

## 10. 界面质量

- [ ] 每个页面在 1280px 和 375px 下没有页面级横向滚动、没有重叠或截断的关键文字
- [ ] 所有列表都有空状态
- [ ] 中文、英文没有漏翻的文案
- [ ] 键盘可以操作抽屉和弹窗（Esc 关闭），焦点可见
- [ ] 浏览器控制台没有报错
